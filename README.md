# Growth Hub Education Platform

Responsive Growth Hub exam-practice website based on the supplied homepage reference and the existing Growth Hub project files.

## Included
- WAEC, NECO, JAMB/UTME, BECE and Command Entrance pathways
- WAEC/NECO subject combination flow; JAMB Use of English plus four selected subjects
- 60-question English/Mathematics sessions and 50-question sessions for other subjects
- Timed multiple-choice practice, question navigation, calculator, scoring and answer review
- Browser-local profile demo and saved practice history
- Light/dark mode, mobile navigation, social links and responsive layout
- PWA manifest and service worker for install/offline shell support

## Run
Open `index.html` for a basic preview. For PWA installation and service-worker caching, deploy the folder to an HTTPS static host (for example GitHub Pages or Netlify).

## Important notes
- The profile/login is a local browser demo, not secure server authentication.
- The included question bank is a starter practice bank. It does not claim to be a verified archive of official 2007/2015 past papers or a fully mapped 2027 syllabus. Sessions are set to the requested lengths, but subjects with fewer authored questions currently repeat shuffled items. Add checked, licensed question sets before public exam use.
- The contact email is a placeholder; replace it with the official Growth Hub contact address before publishing.
